# 10 – User Interface

Exact console output and interaction. All text in English. Demo data is
described in [11-demo-data.md](11-demo-data.md).

## Common formats

| What | Format |
|------|--------|
| Date input | `yyyy-MM-dd` |
| Date-time output | `yyyy-MM-dd HH:mm` (`DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm")`) |
| Distance output (Part 3) | `String.format(Locale.ROOT, "%.1f km", distanceKm)` → `7.6 km` |
| Separator between detail blocks | 40 × `-` |
| Empty result in a list | `  (none)` |
| Error from model/logic | `Error: <exception message>` |

### Activity details block

Labels are left-aligned in 13 characters (`String.format("%-13s%s", label, value)`).

```
Title:       Trip to Preikestolen
Logger:      Kari Nordmann
Registered:  2026-08-15 09:30
Type:        Mountain hike                    ← Part 3
Distance:    7.6 km                           ← Part 3
Sharing:     Shared with group Fjellgjengen   ← Part 2+
Description: Classic hike from Preikestolhytta. Clear weather and a great view over Lysefjorden.
```

`Sharing:` value (Part 2+):
- `Private` when not shared.
- Otherwise `Shared with ` followed by, comma-separated: the person names
  (sorted), then `group <name>` for each group (sorted).
  Examples: `Shared with Kari Nordmann, Lars Haugen`,
  `Shared with group Fjellgjengen`, `Shared with Kari Nordmann, group Fjellgjengen`.

### Activity summary line (Part 2+)

```java
String.format("%3d. %s  %-15s  %s%s", number, dateTime, loggerName, title, shared ? "  [shared]" : "")
```
```
  1. 2026-08-15 09:30  Kari Nordmann    Trip to Preikestolen  [shared]
```

### Count-per-logger table (Part 2+)

```
Logger               Activities
-------------------- ----------
Ingrid Berg                   1
```
Header `String.format("%-20s %10s", "Logger", "Activities")`, rows `"%-20s %10d"`.

## Part 3 – Menu

### General rules
- Every menu is printed with an empty line before its title.
- The menu choice is read with `readInt("Choose an option: ", 0, <max>)`.
- `0` goes back (or exits from the main menu).
- After each action the same menu is shown again.
- Any `IllegalArgumentException`, `IllegalStateException`,
  `NoSuchElementException` or `NullPointerException` from model/logic is
  caught and printed as `Error: <message>`; the menu continues.

### Choosing from a list
Print a heading, then the items numbered `  1. <item>`, then
`readInt("Choose <thing> (0 to cancel): ", 0, n)`. `0` cancels the action
silently. If the list is empty, print `No <things> registered.` (or the
specific message below) and return.

### `InputReader` messages

| Situation | Message (then ask again) |
|-----------|--------------------------|
| Blank text | `Input cannot be empty. Please try again.` |
| Not a whole number | `Please enter a whole number.` |
| Whole number out of range | `Please enter a number between <min> and <max>.` |
| Not a decimal number (both `7.5` and `7,5` are accepted) | `Please enter a number, e.g. 7.5.` |
| Decimal below minimum | `Please enter a number of at least <min>.` |
| Invalid date | `Invalid date. Use the format yyyy-MM-dd, e.g. 2026-10-29.` |
| Not y/yes/n/no (any case) | `Please answer y or n.` |

### Main menu
```
=== Activity Logger v1.0.0 ===
1. Activities
2. Search
3. Loggers
4. Groups
5. Sharing
6. Statistics
0. Exit
```
Choosing `0` prints `Goodbye!` and ends the program.

### 1. Activities
```
--- Activities ---
1. List all activities
2. Show activity details
3. Register new activity
4. Delete activity
0. Back
```
- **List all**: `All activities (<n>):` then summary lines; `No activities registered.` if empty.
- **Show details**: choose activity → details block.
- **Register** (FR1-1, FR2-1):
  1. `Loggers:` list of persons, plus a last item `<New logger>`; `Choose logger (0 to cancel): `.
     For `<New logger>`: `readText("Name of new logger: ")` → `PersonRegister.getOrCreate`.
  2. `readText("Title: ")`, `readText("Description: ")`.
  3. `Activity types:` list of display names; `Choose type (0 to cancel): `.
  4. `readDouble("Distance in km: ", 0)`.
  5. `registeredAt = LocalDateTime.now().truncatedTo(ChronoUnit.MINUTES)`.
  6. Print `Activity registered.`
- **Delete** (FR1-4): choose activity → `readYesNo("Delete \"<title>\"? (y/n): ")` →
  `Activity deleted.` or `Cancelled.`

### 2. Search
```
--- Search ---
1. By date
2. By period
3. By logger
4. By keyword
5. By type
0. Back
```
Inputs: `Date (yyyy-MM-dd): `; `From date (yyyy-MM-dd): ` + `To date (yyyy-MM-dd): `;
choose logger; `Keyword: `; choose type.
Result: `Found <n> activity:` / `Found <n> activities:` then summary lines, or
`No activities found.`

### 3. Loggers
```
--- Loggers ---
1. List loggers
2. Add logger
0. Back
```
- **List**: `Loggers (<n>):` then `  1. <name>`; `No loggers registered.` if empty.
- **Add**: `readText("Name: ")` → `addPerson(new Person(name))` → `Logger added.`

### 4. Groups
```
--- Groups ---
1. List groups
2. Create group
3. Add member to group
4. Remove member from group
0. Back
```
- **List**: one line per group: `  Fjellgjengen (3 members): Ingrid Berg, Kari Nordmann, Ola Hansen`;
  an empty group shows `  <name> (0 members): -`; use `1 member` for one.
  `No groups registered.` if none.
- **Create**: `readText("Group name: ")` → `Group created.`
- **Add member**: choose group, choose logger → `<person> added to <group>.`
- **Remove member**: choose group, choose among its members
  (`The group has no members.` if empty) → `<person> removed from <group>.`

### 5. Sharing
```
--- Sharing ---
1. Share activity with loggers
2. Share activity with group
3. Stop sharing with a logger
4. Stop sharing with a group
5. Make activity private
6. Show activities shared with a logger
0. Back
```
- **Share with loggers** (FR2-3): choose activity; then repeatedly choose logger
  with prompt `Choose logger (0 when done): `; after each: `Shared with <name>.`
- **Share with group** (FR2-3): choose activity, choose group → `Shared with group <name>.`
- **Stop sharing with a logger / group** (EXT-5): choose activity, choose among its
  shared persons/groups (`This activity is not shared with any loggers.` /
  `… any groups.` if empty) → `Stopped sharing with <name>.`
- **Make private** (FR2-4): choose activity → `Activity is now private.`
- **Shared with a logger** (FR2-5): choose logger → result as in Search.

### 6. Statistics
```
--- Statistics ---
1. Activities per logger
2. Shared vs. private activities
0. Back
```
- **Per logger** (FR2-9): the count table; `No activities registered.` if empty.
- **Shared vs. private** (EXT-6):
  ```
  Shared activities:  3
  Private activities: 2
  ```
